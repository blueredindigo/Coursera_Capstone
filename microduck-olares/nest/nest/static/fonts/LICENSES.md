# Fonts

Bundled so the Pond works with no internet connection. All three are under the
SIL Open Font License 1.1 (https://openfontlicense.org), which allows redistribution
alongside software:

- **Fraunces** (latin subset, weights 600–700): Undercase Type.
- **Atkinson Hyperlegible** (latin subset, 400 and 700): Braille Institute of America.
- **Press Start 2P** (latin subset): CodeMan38.

Downloaded from Google Fonts' latin subsets.
